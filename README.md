# 🎯 Chrome Selector Extension

A sleek and interactive **Chrome extension** that lets you **select any element on a webpage** and change its appearance — all from a beautifully designed popup interface!

---

## ✨ Features

- 🔍 **Element Selector** — Click and highlight any DOM element with ease.
- 🎨 **Style Editor** — Instantly change background color, font color, and more.
- ⚡ **Real-time Updates** — See the changes live as you make them.
- 🧠 **Lightweight & Intuitive** — No bloat, just what you need.

---

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Thamidu-Nadun/chrome-selector.git
cd chrome-selector
```

### 2. Load into Chrome

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (toggle at top-right)
3. Click **"Load unpacked"**
4. Select the project folder you just cloned

Boom! The extension is now active 🎉
